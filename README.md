# Netflix Data Analysis & Business Recommendations

## Overview
An Exploratory Data Analysis (EDA) on Netflix's movies and TV shows dataset to identify content trends, release patterns, and viewer demographics for strategic planning.

---

## Key Highlights
* **Content Split:** ~70% Movies vs. ~30% TV Shows.
* **Target Demographic:** `TV-MA` is the top rating (~30%), followed by `TV-14`.
* **Top Production Markets:** United States, India, and the United Kingdom.
* **Series Length:** Most TV Shows on the platform currently have only 1 Season.
* **Core Genres:** Dramas, Comedies, and International Content lead the catalog.

---

## Technical Details
* **Data Prep:** Imputed missing values (`Unknown_*`) and handled time-series parsing.
* **Feature Engineering:** Extracted content durations, added dates (year/month/week), and release gaps.
* **Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn.
